## Requisitos técnicos obligatorios

El proyecto debe:

1. ser una aplicación funcional;
2. ejecutar una llamada runtime a Nebius Token Factory, o ejecutarse/desplegarse mediante Nebius AI Cloud;
3. usar al menos un modelo NVIDIA open source;
4. encajar en una de las cuatro categorías;
5. instalarse y ejecutarse de forma consistente;
6. funcionar como se muestra en el vídeo y la descripción.

## Categorías oficiales

- Coding and agentic engineering.
- Best apps and agents.
- Personal AI.
- Physical AI.

La categoría candidata de Phoenix Action Gate es `Coding and agentic engineering`, pendiente de cerrar el alcance.

## Entrega

Se requiere:

- descripción del proyecto;
- selección de categoría;
- aplicación funcional;
- URL de demo, aplicación alojada o test build, salvo la excepción de Physical AI;
- vídeo público de YouTube de tres minutos o menos, con audio;
- repositorio público accesible para evaluación;
- licencia open source aprobada por OSI, visible;
- README con instalación y ejecución;
- explicación del uso real de modelos NVIDIA y Nebius;
- feedback sobre las herramientas y modelos utilizados.

## Proyecto nuevo o existente

El formulario pregunta si el proyecto existía antes del 26 de agosto de 2026.

`phoenix-action-gate` es un proyecto y repositorio nuevos, creados durante el periodo. Sin embargo, deberá declararse con claridad que investiga y adapta ideas procedentes de una arquitectura Phoenix anterior. No se presentará el trabajo preexistente como construido durante el concurso.

## Tavily

El formulario exige responder si se usó Tavily. Tavily solo cuenta para su premio específico si existe una llamada runtime funcional. No se añadirá de forma artificial.

## Evaluación oficial

1. **Technological Implementation:** calidad de construcción y uso efectivo de Nebius/NVIDIA.
2. **Design:** experiencia completa y coherente, no solo prueba técnica.
3. **Potential Impact:** problema y audiencia reales respaldados por lo demostrado.
4. **Quality of the Idea:** creatividad, uso no obvio y comprensión del dominio.
